# Müllabfuhr

Ein einfacher **Müll-Abholkalender** fürs Dashboard — komplett lokal, kein
Server, keine Cloud, keine API.

## Was es zeigt

- Pro Tonne (Restmüll, Bio, Gelber Sack, Papier, Glas …) die **nächste
  Abholung** mit Datum und Countdown („Heute", „Morgen", „in 3 Tagen").
- Eine **Erinnerungsleiste** in der Tonnenfarbe, wenn heute oder morgen
  abgeholt wird („morgen rausstellen").
- Tonnen sind nach dem nächsten Termin sortiert — die dringendste oben.

## Einrichtung

Widget hinzufügen → Einstellungen → **Schnell hinzufügen** (Restmüll/Bio/
Gelb/Papier/Glas) oder eigene Tonne anlegen. Pro Tonne einstellen:

- **Name** und **Farbe** (Presets bringen die echten Tonnenfarben mit).
- **Rhythmus:** wöchentlich, 14-tägig oder 4-wöchentlich.
- **wöchentlich:** nur den **Wochentag** wählen.
- **14-tägig / 4-wöchentlich:** ein **bekanntes Abholdatum** eintragen — das
  legt Wochentag und Takt fest, alle Folgetermine werden daraus berechnet.

> Tipp: Für 14-tägige Tonnen einfach den nächsten Termin aus dem Abfallkalender
> deiner Stadt eintragen — der Rest rechnet sich automatisch fort.

# Waste collection (English)

A simple **bin collection calendar** for your dashboard — fully local, no
server, no cloud, no API.

**Shows:** the next collection per bin (general/bio/recycling/paper/glass …)
with date and countdown, a reminder bar in the bin's colour when it's due today
or tomorrow, and bins sorted by soonest pickup.

**Setup:** add bins in settings (quick-add presets or custom). Per bin pick a
name, colour and interval — weekly (pick the weekday) or every 2 / 4 weeks
(enter one known collection date, which sets the weekday and phase).
